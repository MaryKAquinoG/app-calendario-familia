# App Calendario Familia

Página estática pensada para generar actividades cortas para niños y fomentar compartir en familia.

Cómo usar (local):
1. Abrir `index.html` en un navegador moderno (se carga PyScript desde CDN).
2. Seleccionar fecha, categoría y tocar "Generar actividad".
3. Guardar la actividad y usar "Generar mensaje para compartir" para copiar un resumen.

Despliegue en GitHub Pages:
1. Crear un repo en GitHub llamado `app-calendario-familia` (o el nombre que prefieras).
2. Subir estos archivos y pushear a la rama `main`.
3. En GitHub → Settings → Pages, elegir rama `main` y root.
4. La URL será: `https://TU-USUARIO.github.io/app-calendario-familia/`
